# Customer Churn Prediction

## Project Overview
This project predicts whether a telecom customer is likely to leave the service using Machine Learning.

## Dataset
- IBM Telco Customer Churn Dataset
- 7,043 customer records
- Target variable: Churn

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
Logistic Regression (Supervised Learning)

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Encoding
6. Feature Scaling
7. Model Training
8. Model Evaluation
9. Customer Churn Prediction

## Model Evaluation
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Objective
To identify customers who are likely to churn and help businesses improve customer retention.
